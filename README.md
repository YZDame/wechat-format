# 微信公众号排版编辑器

[打开雁栖湖版](https://yzdame.github.io/wechat-format/)

把 Markdown 粘到左侧，在右侧预览，点「点此复制」后粘到微信公众号编辑器。

基于 [Lyric 的 WeChat Format](https://github.com/lyricat/wechat-format) 与 [阮一峰的版本](https://github.com/ruanyf/wechat-format)。文章样式改编自[牧码的雁栖湖主题](https://cloud.tencent.com/developer/article/1815183)，由渲染器写入行内样式。
