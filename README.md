# 微信公众号排版编辑器（个人使用）

公众号 LeyuDame 的默认主题。

[打开在线编辑器](https://yzdame.github.io/wechat-format/)

文章 CSS 样式改编自 [牧码的雁栖湖主题](https://cloud.tencent.com/developer/article/1815183)。

网页基于 [Lyric 的 WeChat Format](https://github.com/lyricat/wechat-format) 与 [阮一峰的版本](https://github.com/ruanyf/wechat-format) 打造。 

界面与 Markdown 高亮使用 [Flexoki](https://stephango.com/flexoki)（Steph Ango）进行了微调，支持深浅模式。
